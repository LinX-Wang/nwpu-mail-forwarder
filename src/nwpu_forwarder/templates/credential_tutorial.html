{{ '使用学校邮箱单独生成的 16 位专用密码连接 IMAP。' if school else '开启包含 SMTP 的客户端服务，再生成 16 位授权码。' }}不使用网页登录密码。

    {% if school %}
  1. 登录学校邮箱

    打开 学校邮箱网页版 {{ icon('arrow') }}，由你本人完成学校要求的身份核验。

  2. 进入邮箱密码设置

    点击邮箱左下角的齿轮图标，进入「个人信息」→「邮箱密码」，点击下方「+」。

  3. 生成专用密码

    填写便于识别的名称，例如「NWPU Mail Forwarder」，点击「生成」。

  4. 保存并配置

    妥善保存生成的 16 位密码。客户端账号使用完整的 @mail.nwpu.edu.cn 邮箱地址；通过下方凭据向导配置，然后测试学校连接。

    5. {% else %}
  5. 进入账号与安全

    打开 QQ 邮箱网页版 {{ icon('arrow') }}，登录后选择「设置」→「账号与安全」。旧版入口可能显示为「账户」。

  6. 开启 SMTP 服务

    找到「POP3/IMAP/SMTP/Exchange/CardDAV 服务」，开启包含 SMTP 的服务。此工具使用 SMTP 发送通知。

  7. 完成验证，获取授权码

    按官方页面要求使用绑定手机完成验证；若要求发短信，发送后点击「我已发送」。验证通过后复制并妥善保存 16 位授权码。

  8. 配置并验证发送

    账号填完整 QQ 邮箱地址，客户端密码填授权码。通过下方凭据向导配置后，测试 QQ SMTP，再发送测试邮件确认手机提醒。

    9. {% endif %}
