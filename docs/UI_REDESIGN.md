# 全站 UI/UX 改版与验收

日期：2026-11-16。生产界面已部署，沿用 Flask/Jinja 与现有 API；没有新增生产前端依赖。

登录更新：管理面板改为学号与自设密码双字段，正确匹配两者才能登录。学号配置随非敏感配置迁移，密码仍使用加密凭据；保留 CSRF、登录限速与会话保护。用户名错误与密码错误使用相同提示，账号不在登录页预填。新增登录及学号校验测试后，Windows 98 项测试通过。

后续单屏调整：桌面概览与转发设置在宽度至少 1100px、高度至少 600px 时固定为一屏，页面不整体滚动；活动、任务和必要的设置内容在内部滚动，标题与底部操作保持可见。转发设置为邮件内容、监听策略、转发许可三栏；登录页改为宽双栏，放大产品说明、表单与控件。较小窗口和手机使用流式单列，避免裁切内容。1920×1080、1366×768 已实际断言页面高度不超过视口，保存按钮与页脚在屏幕内，登录与配置操作仍正常。

## 页面与交互

- 220px 桌面侧栏，主内容占满剩余宽度，没有固定最大宽度；标题 30px、统计数字 36px。手机侧栏收起，提供可键盘操作的导航，卡片单列。
- 概览包含真实服务状态、四张 KPI、最近活动与任务列表。启停按钮按状态切换，任务重试连接原有接口；时间异常任务先确认。
- 邮箱配置与转发设置通过同一 /settings 路由的两个视图呈现，同一个表单保留全部现有字段，保存逻辑不变。
- 日志支持本地搜索、级别筛选、复制、15 秒自动刷新和二次确认清空当前视图。清空不会删除服务器日志，并暂停自动刷新；手动刷新可恢复读取。
- 公网路径前缀、CSRF、Cookie、安全响应头及原有登录有效期保留。所有脚本和 SVG 本地托管，符合原有 CSP，不使用 CDN。
- 校徽与 LinX 来源见 [标识资源](BRAND_ASSETS.md)。

现有后端不支持网页修改凭据、手动切换 IDLE、调整自动重试或删除服务器日志，因此这些操作没有新增虚假开关。页面显示凭据向导、自动检测 IDLE 和现有退避策略。

## 修改文件

- templates/base.html、dashboard.html、settings.html、logs.html、login.html：所有页面结构与导航重构。
- templates/components.html：统一图标、状态徽章、操作按钮。
- static/app.css：统一浅色 Design Tokens、全宽响应式布局、控件、状态、交互与动效。
- static/app.js：真实状态刷新、操作提交、反馈、移动导航及日志交互。
- static/nwpu-emblem.svg、linx-lockup.svg、linx-symbol.svg、favicon.svg：本地矢量标识。
- pyproject.toml：打包 JS/SVG；Playwright 只作为可选 ui-test 开发依赖。
- scripts/verify-ui.py、tests/test_ui_templates.py：页面与交互自动化验证。

邮件接收、解析、转发、重试、去重模块、数据库结构及后端 API 未修改。

## 重跑浏览器检查

```bash
python -m pip install -e '.[test,ui-test]'
python -m playwright install chromium
python scripts/verify-ui.py
```

也可以用 --browser 指定本机 Chrome 可执行文件。脚本只创建临时运行目录，不连接学校或 QQ 邮箱。
# 邮件摘要展示（2026-11-16）

最近邮件任务展示真实主题（最多 200 字符）及纯文本正文预览（最多 300 字符，列表显示两行）。任务编号可展开查看。摘要保存在既有 SQLite metadata 中，原始邮件仍在成功发送后删除；数据库结构、发送状态、UID 去重和监听策略保持不变。摘要仅登录后可见，响应不缓存，运行日志不记录邮件内容。HTML 邮件转换为纯文本，模板自动转义，JavaScript 使用 textContent。

旧任务可使用 scripts/backfill-previews.py 在 systemd 提供学校凭据的环境下补取最近最多 50 条记录。只读选择 INBOX，使用 BODY.PEEK 限量读取，并核对 UIDVALIDITY、大小、收件时间和已有 Message-ID；不创建任务、不移动游标、不发送邮件。已删除或不匹配的旧邮件保持摘要不可用。

验证：103 项自动化测试通过；21 项浏览器检查通过，控制台错误 0，1920×1080 与 1366×768 仍为桌面单屏，390px 与 320px 无横向溢出。截图使用隔离环境模拟邮件，生产页面使用真实数据。
