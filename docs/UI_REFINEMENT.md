# 第二轮 UI 精修 · 2026-11-16

保留 Flask/Jinja、浅色主题、Sidebar、西工大校徽和 LinX 原始矢量标识。生产资源均为本地文件，没有新增前端依赖或外部内容请求。

## 页面与交互

- 统一字体与间距变量，主标题 28px、模块标题 16px、正文 14px、辅助文字 12–13px、KPI 30–34px。整理旧桌面/手机覆盖规则，保留概览与转发设置桌面单屏。高度不足时仅记录区或设置主体滚动，标题与保存操作保留。
- 概览的四个状态模块对齐；KPI 同高；活动采用轻量时间线。邮件任务默认显示主题、发件人名称或脱敏地址、收件时间、状态与尝试次数，点击展开短摘要、附件文件名和处理详情。刷新保留展开状态及滚动位置。
- 邮箱配置共用同一模板结构：账户身份、服务器、安全认证、连接状态、测试操作。输入高度 42px。密码始终为固定掩码，修改入口展开现有 SSH 凭据说明。
- 转发设置采用约 65/35 两列，下方为横向授权确认。保留 consent/full_consent/attachments 原始字段与后端验证。IDLE 和重试上限没有可配置接口，因此如实显示自动检测、持续重试及认证/永久错误的处理要求。
- 保存仍通过原有表单 POST，新增未保存、保存中、成功和失败反馈；失败保留输入，监听或发送运行期间禁止保存。复选框取消勾选也会识别为修改，保存期间继续编辑不会误标为已保存。
- 日志为时间、级别、类型、描述四列，点击展开完整脱敏日志行。少量数据自然收缩，大量数据才内部滚动。搜索、筛选、自动刷新、复制和二次确认清空浏览器视图保留，服务器日志不删除。

## 业务与隐私边界

IMAP 连接、扫描、等待、UID 去重、SMTP 发送、任务状态定义、SQLite 表结构及既有接口语义保持不变。仅在既有 metadata 中增加展示用发件人和附件文件名，并通过既有只读摘要补取工具补齐旧任务；不加载或保存新的完整邮件副本，不下载附件，不发送邮件。

正文仍为原有最多 300 字预览。模板和浏览器呈现前隐藏完整链接，脱敏邮箱地址，并以自动转义/textContent 输出。没有外部链接按钮、远程图片或附件下载。刷新去重用的原始摘要签名只存在 JavaScript 内存，不写入 DOM 属性。密码、邮件正文和附件内容不写入运行日志。
