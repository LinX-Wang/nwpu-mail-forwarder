# 配置与凭据

非敏感配置位于 `/etc/nwpu-mail-forwarder/settings/config.json`，通过私有面板修改。修改前暂停监听并等待当前发送完成。临时任务按当前配置发送；改变学校账号或 IMAP 地址会启用独立基线，旧账号待处理任务保留，不会发给新账号。

| 配置 | 默认值 / 行为 |
| --- | --- |
| 学校邮箱地址 | 首次填写完整地址 |
| IMAP | imap.nwpu.edu.cn:993，SSL，实际以学校官方客户端配置为准 |
| QQ 邮箱地址 | 首次填写完整地址，同时作为发送人与收件人 |
| SMTP | smtp.qq.com:465，SSL |
| 模式 | notification；full 需明确确认允许完整转发 |
| 轮询间隔 | 90 秒，可设 60–3600 秒 |
| 大小限制 | 20 MiB，可设 1–100 MiB；最终编码大小及 SMTP SIZE 均检查 |
| 完整模式附件 | 默认保留；关闭时正文内嵌图片仍保留 |

两个协议均使用 TLS 证书验证，不提供忽略证书选项。仅支持隐式 TLS 端口，不自动降级到明文或 STARTTLS。

## 凭据

`sudo nwpu-forwarder credentials` 在交互式终端通过 getpass 输入，使用 systemd-creds 的主机密钥加密，保存到 root 专属的 credentials 目录。systemd 在服务启动时提供只读运行时凭据。用户名和服务器地址不属于密码，仍保存在配置中。

当前方案不依赖 TPM。拥有 root 权限及主机密钥的人能够解密；磁盘快照、迁移备份仍需妥善保护。密码更换后向导重启服务，清除认证暂停状态。

## UIDVALIDITY 重置

正常扫描只比较 UID。重置后重新扫描，排除首次启用时间之前的历史邮件，对完整内容使用 SHA-256、大小与 INTERNALDATE 关联旧任务；不使用 Message-ID 单独去重。

INTERNALDATE 缺失、边界秒不明确或超大邮件内容不完整时进入待确认状态。面板确认后才发送。若服务器重建时改变所有 INTERNALDATE，无法绝对区分历史邮件，可能需要人工核对；不宣称 IMAP UID 重置后的恢复可完全无歧义。

超大邮件只读取前 64 KiB 来生成尽力而为的预览，可能没有可用正文；完整转发超限原因会明确显示。普通待处理邮件原始内容存放在 SQLite 中，成功后逻辑删除，不写入日志。数据库、WAL、系统快照或备份可能保留旧数据痕迹，不保证物理安全擦除。
# 管理面板账号与密码

管理面板使用学号 + 自设登录密码。非敏感的学号保存在配置字段 panel_username，必须为 6–20 位数字；默认留空，没有预置个人账号。密码仍通过 systemd 主机密钥加密保存为 panel_password，不写入 JSON、源码或日志。未配置学号时，不能仅凭密码登录。

首次配置或修改账号、密码，在交互式 SSH 终端执行 `sudo nwpu-forwarder credentials`。输入登录学号，并设置至少 10 字符的登录密码；已有值可留空保留。该密码是面板的自设密码，不是学校客户端密码或 QQ 授权码。完成后向导重启服务，使配置生效。

旧版本升级需要补充 panel_username；已有加密 panel_password 可继续使用。迁移包包含登录学号等非敏感配置，密码仍需在新服务器重新设置。
