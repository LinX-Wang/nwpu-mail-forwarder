# 西工大官方视觉资源来源

2026-11-16 已在本机整理官方素材，位置为 `resources/nwpu-official/`，可打开 `gallery.html` 查看图库。

官方来源：

- [学校形象识别系统](https://news.nwpu.edu.cn/xcb/index/xxsbxt.htm)：校标、校名标准字、标准色等。
- [标准矢量图原始下载](https://news.nwpu.edu.cn/20180109.zip)：CDR 源文件。
- [新版 VI 与使用示例](https://news.nwpu.edu.cn/info/1210/74474.htm)：新版 VI 的 CDR 附件及 27 张示例图片。
- [校徽](https://news.nwpu.edu.cn/info/1210/46709.htm)。
- [校风](https://news.nwpu.edu.cn/info/1210/46715.htm)。
- [校训](https://news.nwpu.edu.cn/info/1210/46716.htm)。
- [校旗使用规范](https://news.nwpu.edu.cn/info/1210/46717.htm)。

已取得 2 套官方 CDR 原稿及 31 张官方位图。未取得可核实的官方建筑剪影或独立地标矢量图集，不把第三方设计或位图描摹结果称作官方矢量图。CDR 包含曲线及嵌入位图，须按具体对象核对导出结果。

尚未核实学校标识文件的开放再分发许可。素材目录被 `.gitignore` 排除；公开源码仅保留这些出处和指引，避免把学校品牌资源混入 MIT 代码许可。当前线上品牌文件没有被替换。

本地说明、哈希清单与图库均在素材目录。运行 `python scripts/package-nwpu-assets.py` 可以对已下载文件重新生成图库及 ZIP；此脚本不上传素材，也不会部署面板。
