# 邮箱客户端凭据获取教程

邮箱配置页的两个账户面板均提供默认折叠的教程，可用鼠标、触摸或键盘展开。教程不读取凭据，不自动打开外部页面，不改变监听状态。

## 西工大客户端专用密码

1. 由本人登录 [学校邮箱网页版](https://mail.nwpu.edu.cn/)，完成身份核验。
2. 左下角齿轮 →「个人信息」→「邮箱密码」，点击下方「+」。
3. 输入便于识别的密码名称，例如 NWPU Mail Forwarder，点击「生成」。
4. 妥善保存生成的 16 位专用密码。IMAP 登录账号使用完整学校邮箱地址，密码使用此专用密码。

服务器参数以学校官方客户端配置为准。

来源：[西北工业大学信息化管理处：生成客户端专用密码](https://it.nwpu.edu.cn/wlfw1/dzyx/sysm/yjkhddl/sckhdzymm.htm)。

## QQ SMTP 授权码

1. 由本人登录 [QQ 邮箱网页版](https://mail.qq.com/)，打开「设置」→「账号与安全」。旧版可能显示为「账户」。
2. 找到 POP3/IMAP/SMTP/Exchange/CardDAV 服务，开启包含 SMTP 的服务。
3. 按官方页面提示使用绑定手机完成验证；若要求发送短信，发送后点击「我已发送」。复制并妥善保存生成的 16 位授权码。
4. SMTP 登录账号使用完整 QQ 邮箱地址，密码使用授权码。默认 SMTP 为 smtp.qq.com:465，SSL/TLS 开启。

修改 QQ 主密码会使已有授权码失效。可以通过「设备管理」→「授权码管理」停用或管理授权码。

来源：[QQ 邮箱：如何开启 POP3/SMTP/IMAP 服务并获取授权码](https://help.mail.qq.com/detail/108/1087?expand=8)、[授权码设置与管理](https://help.mail.qq.com/detail/108/1091/)。

## 在本工具中配置

服务器版不通过网页接收邮箱凭据。SSH 登录部署服务器，在隐藏输入向导中配置：



    sudo nwpu-forwarder credentials

留空保留已有值。完成后按现有运维流程重启服务并在邮箱配置页测试连接。测试邮件只需少量验证，不要反复向学校邮箱发送测试邮件。

不要将凭据写入源码、普通配置、日志、截图或聊天。网页版登录密码、学校客户端密码、QQ 授权码及本工具面板密码是不同的凭据。
