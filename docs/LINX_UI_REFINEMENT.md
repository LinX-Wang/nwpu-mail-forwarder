# LinX UI 规范精修

参考：[LinX UI 风格规范](https://github.com/LinX-Wang/linx-ui/blob/main/docs/STYLE_GUIDE.md) 与字体、组件规范。2026-11-16 更新。

## 本次变化

- 新增 raised 语义底色：输入框、下拉框和日志表头与卡片表面区分。输入获得焦点后使用卡片表面色和清晰焦点圈。
- 新增 selection、selection-soft、selection-border：导航、主题分段控件、次按钮悬停和复选框统一青绿色表达。日间与夜间分别定义文字、边框和低浓度底色。
- 保存、启停、连接测试和登录使用共享按钮加载呈现。原始内容隐藏但保留布局占位，加载提示覆盖原位，完成或失败后恢复原始 DOM，宽高不跳动。
- 修正夜间主按钮悬停时文字颜色，使用专门的 on-accent 对比色。
- CSS 分为三个职责文件：tokens.css 管理颜色、字号和间距；components.css 管理控件、卡片、记录、品牌和反馈；app.css 管理工作台几何及响应式。base.html 按这个顺序加载，全部 URL 保留自动内容指纹与静态缓存。
- 合并重复的通用选择器，清理已经不用的侧栏旧样式；保留媒体查询的覆盖顺序。

保留正文 15px、辅助文字 13–14px、统计数字 34–36px，以及四页桌面单屏、手机响应式、统一页脚、LinX 出品居中和官方折叠教程。

## 验证

- Python：113 项测试通过。
- 浏览器：37 项检查通过，控制台错误 0；三种桌面、两种手机尺寸，两种主题、四页布局与既有操作通过。
- 保存和启停按钮在请求挂起时，加载前后宽高差小于 1px。
- 新拆分的 CSS 文件正确服务与缓存；敏感页面/API 继续 no-store。
- 页面切换继续复用本地字体与静态文件，没有增加外部 CDN 或前端框架。
